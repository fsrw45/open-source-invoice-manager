# Contributing to Open Source Invoice Manager

Thank you for your interest in contributing to Open Source Invoice Manager! 🎉

We welcome bug reports, feature requests, documentation improvements, and code contributions.

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Make and test your changes.
5. Commit your changes.
6. Push your branch.
7. Open a Pull Request.

## Development

This project uses plain:

- HTML5
- CSS3
- JavaScript

There are no required frameworks or build tools.

To run the project locally, open `index.html` in a browser.

You can also use a simple local server:

```bash
python -m http.server 8080
